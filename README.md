# React Text Analysis Application

A React-based text analysis application built as a reusable front-end project. The application demonstrates component-based React development, client-side routing, UI state management, theme switching, alerts, and responsive interface patterns.

## Features

- React component-based architecture
- React Router navigation
- Text analysis interface
- Light and dark mode
- Alert/notification feedback
- Reusable Navbar, TextForm, Alert, and About components
- Responsive Bootstrap-based UI

## Tech Stack

- React.js 18
- JavaScript (ES6+)
- React Router
- Bootstrap
- CSS3
- Create React App
- Git/GitHub

## Getting Started

```bash
npm install
npm start
```

The development server runs on `http://localhost:3000`.

## Production Build

```bash
npm run build
```

## Deployment

The project includes GitHub Pages deployment scripts:

```bash
npm run deploy
```
